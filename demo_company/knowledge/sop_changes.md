# Employee Record Changes SOP

Owner: People Ops. Applies when an existing employee's department, manager, start date or access level changes.

## Procedure
1. Sign in to AcmeHR with the ops service account (see the Systems Guide).
2. Find the employee in the directory by name or email, open their record and choose Edit employee.
3. Change only the fields that were requested and save. Never change anything else on the record.
4. Update the same employee's row in the team roster (data/team_roster.csv) so it matches AcmeHR. For a department change, the roster department column must change too.
5. Access level changes to admin or finance are privileged and need human approval before saving.

## Completion criteria
- AcmeHR shows the new value and every other field is unchanged.
- The roster row for the employee matches AcmeHR and there is still exactly one row for them.
