# Employee Offboarding SOP

Owner: People Ops + IT. The request normally names the person only.

## Procedure
1. Sign in to AcmeHR with the ops service account (see the Systems Guide).
2. Find the employee in the AcmeHR directory by name. If several people match or none do, ask a human; never guess.
3. Deactivate the employee in AcmeHR from their detail page. Deactivation revokes all access and is irreversible without IT, so it needs human approval first.
4. Update the team roster (data/team_roster.csv): set status to inactive for that employee's email.

## Completion criteria
- AcmeHR shows the employee as inactive.
- The roster row for the employee has status inactive.
